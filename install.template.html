HTML Review

在任意 HTML 页面上直接改字、点选加批注，一键复制修改要求交给 AI。压缩后 {{SIZE_KB}} KB，无外部依赖。

方式一：书签栏一键注入（推荐）

把下面的按钮拖到浏览器书签栏。打开任意页面后点一下书签，审阅工具就会出现在右下角；再点一次打开修改清单。

HTML Review （完整内联版，任何页面可用）

HTML Review · 本地加载 （只对本地 file:// 页面有效，每次加载 dist 里最新构建的脚本，适合开发时用）

方式二：在 HTML 里挂载

在页面 </body> 前加一行：

<script src="html-review.js"></script>

也可以把 html-review.js 复制到页面所在目录，写成 src="html-review.js"，这样文件夹移动或发给别人也能用。

快捷键

按键作用
T 或 Alt+T改字模式：悬停高亮可改的文字，点击直接修改；Enter 保存，Shift+Enter 换行，Esc 放弃
C 或 Alt+C批注模式：单击选中，拖拽框选，Shift+单击多选，Alt+↑/↓ 切换父子元素
Esc逐级退出：关闭弹窗、清空选择、退出模式、关闭清单

中文输入法开启时单字母会被输入法接收，请用 Alt 组合键。
