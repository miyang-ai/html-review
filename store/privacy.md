# HTML Review 隐私说明 / Privacy Policy

## 中文

HTML Review 不收集、不上传、不出售任何用户数据。

- **插件不联网**：插件代码全部打包在安装包内，运行时不发起任何网络请求，不加载远程代码。
- **只在你点击时运行**：插件仅在你点击图标或按快捷键时，作用于当前这一个标签页（Chrome 的 activeTab 权限），不会读取其他标签页或在后台访问网页。
- **数据只存在你的浏览器里**：你在页面上做的改字和批注，保存在该页面的浏览器本地存储（localStorage）中。插件和开发者都无法访问这些数据。清除浏览器网站数据即可删除。
- **剪贴板**：只有你点击「复制修改要求」时，插件才会把修改单写入剪贴板；插件不读取剪贴板。
- **导出文件**：只有你点击「导出修改单」时，才会在本地生成 XML 文件。

如有疑问，请联系 contact@miyang.ai。

## English

HTML Review does not collect, transmit, or sell any user data.

- **No network access**: all code ships inside the extension package. It makes no network requests and loads no remote code.
- **Runs only when you click**: the extension acts only on the current tab, only when you click its icon or press its shortcut (Chrome's activeTab permission). It never reads other tabs or accesses pages in the background.
- **Your data stays in your browser**: edits and comments are stored in that page's localStorage in your browser. Neither the extension nor the developer can access them. Clearing site data in your browser deletes them.
- **Clipboard**: the extension writes the change request to your clipboard only when you click "Copy change request". It never reads the clipboard.
- **Exported files**: an XML file is created locally only when you click "Export".
