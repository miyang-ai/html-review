# Chrome 应用商店文案（简体中文）

## 名称（manifest 自动读取，≤75 字符）

HTML Review · 页面改字与批注

## 简介（manifest 自动读取，≤132 字符）

在任意网页上直接改字、点选加批注，一键复制精确的修改单交给 AI 改源文件。只在你点击时作用于当前标签页。

## 类别

开发者工具（备选：工作流程与规划）

## 详细说明

用 AI 写出来的报告、融资材料、产品页、落地页，越来越多是 HTML。改这些页面通常要在浏览器和编辑器之间来回切换，再费力描述「第几页哪张卡片哪句话」。HTML Review 让你在页面上直接改，改完一键交给 AI。

【改字】按 T（输入法开着时按 Alt+T），鼠标移到哪里就高亮哪里能改，点击直接改字，回车保存。改动实时保存在浏览器本地，刷新也不会丢。

【批注】按 C（或 Alt+C），单击选中元素、拖拽框选一片区域、Shift 多选，写下修改意见，还能追加评论。

【交给 AI】点「复制修改要求」，得到一段完整的提示词和 XML 修改单：每条都带 XPath、CSS 选择器、所在章节、原文和新文或批注意见。粘贴给 Cursor、Claude Code、Codex 等 AI，它就能精确找到源码位置去改。

【自动核对】AI 改完源文件后刷新页面，已经生效的改字会自动标记为「已生效」。

更多特点：
- 只在你点击图标或按 Alt+Shift+R 时，作用于当前标签页；安装时不申请「读取所有网站数据」权限
- 修改记录只保存在你的浏览器本地，不上传、不联网
- 页面原有的快捷键（例如幻灯片方向键翻页）照常工作，改字时自动屏蔽
- 设置了严格内容安全策略（CSP）的网站也能正常使用
- 支持本地 HTML 文件（需在插件详情页打开「允许访问文件网址」，首次使用会引导）
